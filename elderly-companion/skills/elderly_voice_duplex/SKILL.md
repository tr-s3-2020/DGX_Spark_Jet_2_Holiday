# elderly-voice-duplex 技能定义

## 定位

解决老人说话停顿长、语速慢、发音轻、偶尔伴随咳嗽叹气的**交互延迟与打断**问题。
它是陪伴产品的声音入口：老人听到的、说出的每一句话都经过这一层。

## 核心能力

### 1. 在想词 vs 已说完（本技能的灵魂）

老人说"我昨天那个什么……嗯……"的时候，绝大多数对话产品会判定"说完了"，
然后强行给一个答非所问的回答。本技能分三层处理：

```
第一层  HesitationScorer（本地启发式，零延迟）
        结尾是省略号        -> THINKING
        结尾撞上填充词      -> THINKING   嗯/呃/这个/那个/就是/后来呢/我想想…
        有句末标点          -> COMPLETE
        只到逗号/顿号       -> UNCERTAIN
        发言过短(≤3字)      -> UNCERTAIN

第二层  模型判定（仅 UNCERTAIN 时）
        用 build_filler_prompt 让模型判断该不该垫一句

第三层  动作分叉
        COMPLETE  -> 收轮，走完整回复
        THINKING  -> 只放垫音，不收轮，继续听
```

垫音示例："诶，您慢慢想，我等您。" / "嗯，我在听呢。" / "不着急，您想着说。"
硬约束：**不超过 12 字**，不提问，不替老人把话接下去。

### 2. 全双工与打断

状态机四态，`duplex.py`：

```
LISTENING ──收轮判定──> THINKING ──首字到达──> SPEAKING ──自然播完──> LISTENING
    ▲                                                      │
    └──────────────────── 老人开口(barge-in) ──────────────┘
```

- `SPEAKING` 期间持续监听；能量超过阈值且**持续 120ms** 才认定是插话
  （老人声音轻，阈值要低；但不能低到环境噪声就触发）
- 停嘴后留 250ms 冷却，避免把 TTS 尾音当成插话
- 咳嗽/叹气（短于 350ms 的发音）直接忽略

### 3. 医疗安全围栏

老人问"我降压药今天能不能吃两颗"时，**任何**医疗建议都是不可接受的风险。
当前实现是确定性预过滤，命中即返回标准话术，根本不进模型：

| 分级 | 触发示例 | 动作 |
|---|---|---|
| P0 | 加倍服药、自行停药、剧烈胸痛/呼吸困难、跌倒起不来 | 拒绝建议 + 提议帮拨子女电话 |
| P1 | 头晕/头痛/恶心/腹痛/腿沉/失眠 | 顺势关切 + 记录 + 告知子女 |

后续可叠加 NeMo Guardrails（Colang）作为第二层；当前的确定性层保留，
因为它零依赖、可单测、行为确定。

### 4. 延迟预算

| 环节 | 实测 | 预算 |
|---|---|---|
| LLM 首字（关思考） | **109ms** | 500ms |
| LLM 整句 | ~400ms | — |
| 端到端首音 | 待接 TTS 后实测 | 300~500ms |

## 边界（本技能不负责）

- **不保存长期记忆**：那是 `life-memoir-retriever` 的职责，这里只在内存里
  保留最近 20 轮对话
- **不生成家属日报**：那是 `family-digest-sync` 的职责；本技能只把
  `safety_level` 和原文抛出去，供其消费
- **不做外呼调度**：什么时候打、打给谁由上层决定，本技能只管"接通之后"
- **不采集音频**：本机无声卡，采音/放音在老人端设备上做，这里只收帧

## 扩展方式

加一个"技能"= 在 `TOOLS`（见 `scripts/agent.py`，位于部署仓库）里注册一个函数。
本文件描述的是**声音交互层**本身的能力，不是工具表。

## 已知限制

1. **中文 ASR 未验证**。候选 `nvidia/nemotron-3.5-asr-streaming-0.6b`，
   FLEURS 上中文 CER 约 19–21%；老人发音含混时大概率更差。
   **必须用真实老人语音实测**，不行就走 NVIDIA 的 fine-tune 路径。
2. **音色克隆不可用**。MagpieTTS v2607 起移除了 zero-shot 克隆（安全原因），
   "亲切晚辈音色"只能用内置音色，或回退早期版本 / 改用 Riva。
3. **垫音目前是预置句 + 模型生成二选一**，还没做"垫音池按情境轮换"，
   重复播放同一句会被老人听出来。
