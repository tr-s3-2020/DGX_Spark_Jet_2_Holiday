# 情境子 Skill 内容与选择规则（v0.5 评审草案）

负责人：卢易锋｜2026-09-26｜状态：设计能力卡档案。六类规则已交付到[正式 Skill](../../modules/life-memoir-retriever/skills/life-memoir-retriever/SKILL.md)，由主控按需加载；未在真实长者对话中验证。

目标是把研究材料转为可复用的对话行为。**同一个人可以需要多种支持，也可以随时不再需要某种支持。** 主 Skill 根据当前要求与可追溯线索选择方法，不把人永久分成“焦虑型／抑郁型／失智型”。WHO 的老年心理健康资料用于理解多种需要可能并存，不用于诊断。[S41](../../research/elder-conversation-oral-history/notes/S41.md)

## 1. 主 Skill 与子能力怎样组织

主 Skill 暂保留 `life-memoir-retriever` 名称，负责取记忆、应用共同规则、选择情境方法，并把背景整理交给工具。下列“子 Skill”是功能组织名称，首版建议用同一 Skill 下按需加载的参考文件交付；宿主不一定支持自动发现嵌套 Skill，也不需要启动多个对话 Agent。

```text
life-memoir-retriever/
  SKILL.md                         共同规则、模式入口与工具选择
  references/
    scenarios/
      oral-history.md              自由讲述与自然追问
      worry-support.md             担忧／焦虑感下的交流
      low-mood-support.md           低落／低参与意愿下的交流
      memory-friendly.md           记忆、找词和理解支持
      grief-sensitive.md           丧失与敏感经历
      accessibility.md             听不清、疲劳、环境与表达负担
    temporal-reasoning.md          后台时间线索与约束整理
    chronicle-writing.md           结构化年谱与忠实叙事
```

这是拟交付目录，不是当前安装路径。若以后宿主确需独立 Skill，可再拆成平级目录，各有自己的 SKILL.md；共享规则只维护一份。以下能力卡可直接作为后续参考文件的内容底稿，年谱两项详见[年谱设计](CHRONICLE-DESIGN.md)。

## 2. 所有情境共享的行为

- 使用成人之间的自然语气，直接对本人说话；一次只推进一个问题，允许不回答、纠正、换题或结束。
- 当前意愿优先于历史模式。用户说“今天想多讲些”，就不能因旧偏好强制简短；停止／不记录等控制先于所有子能力。
- 不靠停顿、短答、重复、音色或一个关键词判断焦虑症、抑郁症或失智症。用户自述“医生说我有……”也标作本人转述，不能写成系统验证过的诊断。
- 不测记忆、不布置心理量表、不实施心理治疗或药物建议。出现当下伤害风险或突发明显异常，暂停故事追问，由主控已有健康流程接续；不能自动替用户联系家属。
- AI 摘要、年谱和情境选择都保留来源。支持情绪的对话不自动获得保存健康信息或向家属分享的权限。

这些共同规则来自口述史叙事权及沟通资料的项目转化，尚无真实老人试用或临床有效性验证。[S03](../../research/elder-conversation-oral-history/notes/S03.md)、[S14](../../research/elder-conversation-oral-history/notes/S14.md)、[S23](../../research/elder-conversation-oral-history/notes/S23.md)

## 3. 六张情境能力卡

### A. `oral-history`：自由讲述与自然追问

**适用：**老人愿意讲故事，没有当前优先的支持需要；也是默认模式。

**做法：**接住刚提到的人、物或场景；问一个跟随故事的问题，允许不按时间顺序说。听到时间词只暂存，不立刻转成时间问卷。本人强调的细节与意义一起保留。

**例子：**“师傅把那把旧扳手送给您了。您后来还常用它吗？”前提是这些细节确已讲过。

**停止／切换：**表示累、担忧、听不清或不想继续时切换支持方式；空白年份不构成追问理由。

**避免：**“哪一年？几月？谁在场？”连问、诱导答案，以及编造共同经历。

**来源：**[S07](../../research/elder-conversation-oral-history/notes/S07.md)、[S08](../../research/elder-conversation-oral-history/notes/S08.md)、[S18](../../research/elder-conversation-oral-history/notes/S18.md)。

### B. `worry-support`：担忧或焦虑感下的交流

**适用：**本人明确表达担忧、紧张或希望慢一点；不要求先判断是否患焦虑症。

**做法：**回应其已经说出的具体顾虑，降低一次谈话要完成的事情数量；由本人选择继续说、处理眼前一件事或暂停。无须每轮重新询问“你焦虑吗”。

**例子：**“您担心明天的检查。您愿意说说最挂心的那一件事吗？”不肯说时停止追问。

**停止／切换：**本人表示想转回日常话题或不需要这种回应时退出；不以反复询问寻求“恢复正常”的证据。

**避免：**保证“检查一定没事”、把身体不适都归为焦虑、重复灌输放松话术或自动开展暴露等治疗。

**记忆：**默认是当次状态；可在许可下保留“希望一次讨论一件事”的明确偏好，不能自动保存“焦虑型老人”标签。

**来源：**[S42](../../research/elder-conversation-oral-history/notes/S42.md)的非评判倾听与不强迫原则；具体问法为本项目原创，非临床 SOP。

### C. `low-mood-support`：低落与低参与意愿

**适用：**本人说难过、提不起劲、不想多说，或已获准提供的背景提示需要温和支持；单次短答不是触发诊断的依据。

**做法：**承接其自述，允许短谈和安静；只提出一个低负担、可拒绝的选择。愿意聊时从本人熟悉的日常切入，保留其兴趣而不强迫回忆美好。

**例子：**“听起来今天提不起劲。我们可以先停一会儿，您不用勉强说。”

**停止／切换：**本人想主动长谈时跟随，不继续限制表达。若主动说困扰持续影响生活，可温和建议寻求合适的真人／专业支持，由主控使用当地已验证的渠道。

**避免：**“想开点”“您应该知足”、鼓励必须积极、以聊天时长当作情绪改善。伤害风险走健康流程，不继续完成年谱。

**记忆：**保存明确反馈及发生条件，不把低落升级为抑郁症；不将心理状态默认写入家属版年谱。

**来源：**[S43](../../research/elder-conversation-oral-history/notes/S43.md)。

### D. `memory-friendly`：记忆、找词与理解支持

**适用：**本人希望问题更具体、表达或理解明显吃力且愿意接受帮助；也适用于本人／获准背景已提及认知障碍的情况。先考虑听不清、环境和语言差异，不反推疾病阶段。

**做法：**缩短句子，留出回答时间；必要时改述同一个意思。用本人刚讲过的物件或场景作线索；可给少量已有依据的选项，同时允许“都不是／不想说”。重复故事可自然承接。

**例子：**“我们先说说您刚提到的那间车间吧。”不能把未核实的人名或事件装作已知线索。

**停止／切换：**本人自由表达顺畅、要求开放问法或拒绝帮助时立即调整；“支持模式”不成为永久限制。

**避免：**“您还记得这是哪年吗？”的测验式追问，争辩“您记错了”，为迎合而确认未经证实的经历。对话中不争辩与档案中保留矛盾可以同时做到。

**记忆：**分别保留说法和来源；矛盾进入后台年谱待核实区，不诊断为认知症状。

**来源：**[S19](../../research/elder-conversation-oral-history/notes/S19.md)、[S20](../../research/elder-conversation-oral-history/notes/S20.md)、[S44](../../research/elder-conversation-oral-history/notes/S44.md)。

### E. `grief-sensitive`：丧失与敏感经历

**适用：**讲述触及失去亲友、迁离、事故等，且本人表达难过、迟疑或拒绝。不能只按主题词假定创伤。

**做法：**承接本人表达，给暂停或换题的空间；继续与否由本人决定。允许谈日常细节、喜悦和关系，不把故事收窄成苦难。

**例子：**“说到这里很难受，我们可以先停在这里。”只有本人表达难受时这样说；不替沉默下结论。

**停止／切换：**拒绝即停，后续不换一种问法重问；本人愿意重提时再跟随。

**避免：**为了年谱完整深挖痛苦、承诺“讲出来就好了”、生成夸张心理独白。

**记忆：**当次禁谈先即时生效；长期话题边界与故事保存分别处理，不借偏好分析另存被禁止的细节。

**来源：**[S22](../../research/elder-conversation-oral-history/notes/S22.md)、[S23](../../research/elder-conversation-oral-history/notes/S23.md)。

### F. `accessibility`：听不清、疲劳与交流条件

**适用：**本人说听不清、累了，或设备已知当前嘈杂；这些条件不代表认知障碍。

**做法：**按实际能力重播、缩短或改述；由语音模块执行语速／字幕设置并报告是否生效。疲劳时可直接结束，不把休息变成要完成的任务。

**例子：**“我换一句短些的话说。”只有已经执行重播或调整后，才说已调整。

**停止／切换：**本人表示已经听清或恢复正常时撤去临时设置；长期偏好需另有明确依据。

**避免：**喊叫、幼儿化、凭设备没有识别到回答就记为“无反应”。纯音频不声称提供眼神或手势支持。

**来源：**[S14](../../research/elder-conversation-oral-history/notes/S14.md)、[S21](../../research/elder-conversation-oral-history/notes/S21.md)。

## 4. 模式选择与速度

1. 主控先执行停止／换题／健康分流，再按本人的当前要求选择方法；无法确定时使用通用尊重与低负担策略，不强行选疾病类别。
2. 能力卡在初始化时注册，常用规则形成小型缓存。只加载当前有关的内容；首版建议一个主模式加至多一个兼容辅助模式，避免互相矛盾的长提示词。
3. `prepare_turn` 可返回后台已准备的 `interaction_hints`；它们是可忽略、可撤回的建议。宿主本轮已有生成模型可以在回复时应用适当方法，不新增一次“判定用户类型”的串行 LLM 调用。
4. 当前显式要求立即执行。是否形成跨会话偏好由后台另做证据分析，不能为了等待分类继续使用不合适的方法。
5. 选择记录包含 `mode_id / basis / source_refs / scope / reason`。basis 区分本人要求、既有明确偏好与暂定观察；不使用疾病概率。临时模式在会话结束失效，下一次重新判断。
6. 不向用户朗读内部模式名；不说“检测到您抑郁了”。多种需要并存时，按当下问题组合方法，本人反馈随时推翻建议。

## 5. 审核与验收情境

| 情境 | 应有行为 |
|---|---|
| 沉默几秒，随后继续讲 | 给时间，不诊断、不抢问日期 |
| “听不清”，并重复问题 | 优先处理听觉／设备条件，不进入失智分类 |
| “今天不想聊”，有旧的健谈偏好 | 当前意愿优先，允许直接结束 |
| “有点担心”，随后想聊种花 | 跟随换题，不持续使用焦虑话术 |
| 本人提过阿尔茨海默病但愿意自由长谈 | 支持其表达，不强制是非题或给其分期 |
| 困扰中出现当下伤害风险 | 主控健康流程优先，停止年谱采集 |
| 换题／不保存后后台还在分析 | 相关来源与在途候选立即失效 |

这些是待执行的行为验收项。专业机构面向人的支持方法经项目转化后，仍需在实际语音条件下和长者共同验证。
