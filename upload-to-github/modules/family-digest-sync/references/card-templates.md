# 卡片文案模板（v0.1，确定性）

家属侧文案**不交给模型自由发挥**。理由：家属收到的是"关于亲人的判断"，可预期性 > 文采。
模型润色适配器默认关闭（`NullSummarizer`），开启后也只能规范化排版，不得引入新事实。

## 标题

| 档 | 模板 |
|---|---|
| P0 普通 | `【需要立即关注】{称呼} {日期}` |
| P0 用药/安全（且已获 medication_safety 授权） | `【需要立即关注】用药/安全风险，建议尽快联系{称呼}` |
| P1 | `【今天需要留意】{称呼} {日期}` |
| P2 | `【今日摘要】{称呼} {日期}` |

## 段落

### 健康观察

```
· {类型}：{脱敏后的 detail}（轻微 / 中等 / 较明显）
```
类型对照：`symptom→身体不适`、`sleep→睡眠`、`pain→疼痛`、`medication→用药`、`mobility→行动`、`appetite→食欲`、`other→其他`、`none` 不出现。
无条目时固定一行：`· 今天没有需要特别说明的健康观察。`
未授权：`（未获得健康摘要授权，本段不展示）`

### 近期回忆（来自 C）

```
{脱敏后的 narrative}
```
未授权：`（未获得回忆摘要授权，本段不展示）`
未就绪：`（回忆摘要尚未生成，本次不展示）`

### 说明（仅当需要提醒时出现）

```
· 本次未能获取健康信息，不能据此判断老人没有异常。
· 本次对话未识别出明确的健康信号，不等于没有问题。
· 健康模块本次曾调用语义模型但未稳定返回，不能据此认定没有问题。
```

## 绝对禁止出现的措辞

- "状况良好""一切正常""没有问题""健康无异常" —— 只要 `acquisition != acquired` 就不允许。
- 任何剂量、用药建议、诊断性表述（如"可能是关节炎""建议加半片"）。
- 未经脱敏的手机号、身份证号、银行卡号、门牌号。
- 把 C 的候选年份润色成确定年份。
