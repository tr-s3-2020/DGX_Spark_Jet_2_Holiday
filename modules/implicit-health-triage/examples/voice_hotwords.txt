# ASR 热词表（word boosting）—— 给 elderly-voice-duplex 使用
#
# 为什么需要这个文件
# ----------------
# 中文 ASR 最典型的失效模式是同音字误识，而且恰好集中在用药词汇上：
#
#     药 → 要        颗 → 棵        片 → 篇
#     减 → 简        停 → 亭        剂 → 记
#
# 下游可以用正则补一部分，但**同音字无法穷举**——补得越多，误伤正常句子的
# 风险越大。真正有效的办法是在上游做 word boosting，把下面这些词加进
# ASR 的热词表。**上游配一次，整条链路受益。**
#
# 怎么用
# ------
# 主流 ASR 都支持，参数名不同：
#
#   NVIDIA Riva ASR     riva.client.asr.RecognitionConfig(
#                           word_boost=[...], boost_score=10.0)
#   Whisper / faster-whisper   initial_prompt="降压药 降糖药 止痛药 …"
#   FunASR / Paraformer  hotword="降压药 20 降糖药 20 …"（词 + 权重）
#   Qwen-Audio           system prompt 里列词，或后处理纠错表
#
# 权重建议：核心药名给高权重（Riva boost_score 10~20），量词给中等（5~10）。
#
# 验证方法
# --------
# 配好之后用 scripts/check_voice_input.py 跑一遍真实录音的转写结果，
# 它会指出哪些句子"看着像用药询问但没被拦住"，那些就是还漏的同音字。
