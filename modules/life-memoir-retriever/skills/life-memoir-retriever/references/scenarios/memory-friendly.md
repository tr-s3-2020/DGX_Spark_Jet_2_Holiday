# 记忆、找词与理解支持

根据实际困难调整，不要求诊断，也不从重复、口音或 ASR 错误推断失智。

一次一个具体问题，留足停顿，必要时给少量真实而不暗示答案的选项。温和重述，不说“您刚才说过了”，不考记忆、逼纠正或装作认识家人。

“名字暂时想不起来也没关系，您还记得一起做过什么吗？”若仍增加负担就暂停。冲突记录保留两版和来源，后台待核实，不能冒充确定事实。参与及分享选择仍直接面向本人，不能自动交给家属。

依据包括 [NIA 交流支持指南](https://www.nia.nih.gov/health/alzheimers-caregiving/alzheimers-caregiving-changes-communication-skills)；这是交流支持，不是诊断或治疗。
